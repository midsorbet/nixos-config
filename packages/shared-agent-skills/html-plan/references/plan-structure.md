# Plan structure

Use this reference only when the source material needs explicit planning structure.

- Use phases or numbered sections for real sequence.
- Use status only when the source defines status or evidence supports it.
- Name owners and collaborators only when provided.
- Show dependencies and risks where they affect order or completion.
- Keep acceptance checks attached to the work they qualify.
- Separate decisions, assumptions, and unresolved questions.

Use tables for exact mappings, comparisons, or repeated fields. Use a flow or timeline only when it materially improves understanding of order. Keep substantial prose as prose rather than forcing every paragraph into a card.

Improve grammar and hierarchy without inflating an implementation plan into strategy. Do not add a timeline, progress percentage, badge, dashboard summary, or decorative metric merely to fill the page.
