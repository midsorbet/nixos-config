01 / Architecture

Three control planes, one workstation

The profile does not pretend that Nix controls the Windows desktop. WinGet owns native packages, PowerToys owns desktop behavior, and WSL carries the Linux development environment.

Native package plane

WinGet Configuration

  • PowerToys desktop utilities
  • Windows Terminal shell surface
  • PowerShell Windows automation
  • WSL Linux substrate
  • VS Code editor and Remote WSL
Desktop control plane

PowerToys + Windows

  • Command Palette launches and searches
  • Window Hopper changes same-app windows
  • FancyZones places and rotates windows
  • Workspaces restores app arrangements
  • Native desktops separate contexts
Development plane

Terminal + WSL

  • Maple Mono NF at 12 pt
  • Alt+h/j/k/l pane focus
  • Alt+Shift+h/j/k/l pane resize
  • NixOS-WSL shared CLI environment
  • VS Code Remote Linux-side editing

05 / Boundaries

Strong keyboard workflow, not a tiling window manager

The boundary is deliberate. Microsoft-native controls cover the daily workflow without pretending to implement Paneru operations that Windows lacks.

Configured and available

  • Keyboard launch and search
  • Global and same-app window switching
  • Keyboard zone placement
  • Cross-monitor window rotation
  • Saved application arrangements
  • Pinned reference windows
  • Virtual desktop navigation
  • Paneru-like Terminal pane focus
  • Batch rename and HEX color capture

Intentionally not claimed

  • Spatial focus between arbitrary desktop windows
  • Directional swap with a neighboring window
  • Automatic tiling and rebalancing
  • Direct Alt+1..9 desktop selection
  • Keyboard send-to-desktop
  • Per-monitor virtual workspaces
  • Paneru's scrollable strip and stack model
  • Third-party window managers or hotkey daemons

How the profile lands on the laptop

Each mutation is explicit. Run the checks first, then apply only the reviewed layers that company policy permits.

.\bootstrap.ps1 -InstallCommandPaletteFragment

Install Terminal settings

Merge the theme, profile defaults, and pane actions after starting Terminal once.

.\bootstrap.ps1 -InstallTerminalFragment

Capture installed schema evidence

Export the schemas from the laptop's installed PowerToys before future setting changes.

.\bootstrap.ps1 -ExportPowerToysSchemas
